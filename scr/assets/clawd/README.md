# Clawd Assets

This folder stores normalized Clawd image assets.

## Naming Convention

- Use `clawd-{variant}.png`
- Use lowercase letters only
- Use hyphen-separated variant names (kebab-case)

## Source of Truth

- Asset metadata is managed in `index.json`
- Add new assets in both:
  - the image file in this folder
  - one entry in `index.json`
