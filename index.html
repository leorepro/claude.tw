這場活動適合誰 Who Should Attend

這是一場專為 學生與 Claude Code 新手 設計的入門分享。你會先看到講者現場示範如何用自然語言打造 App，再透過 Lightning Talks 聽見參與者的真實實作與心得。不必懂語法，也能輕鬆理解 Claude Code 的玩法與可能性。 A beginner-friendly sharing session for students and Claude Code newcomers. You'll watch a live demo of building an app with natural language, then hear real participant projects and takeaways in the Lightning Talks. No syntax required — just come curious and see what's possible with Claude Code.

你會學到什麼 What You'll Learn

  • 現場用 Claude Code 從零建立 App，全程不寫程式Build an app from scratch with Claude Code — no coding required
  • AI 溝通技巧：規劃、迭代與 Prompt 心法AI collaboration: planning, iteration, and prompting techniques
  • 認識 AI 開發工具：Skills、MCP、Agents 的差異AI dev tools: the difference between Skills, MCP, and Agents
  • App 開發專用 Skills 介紹A walkthrough of Skills built for app development
  • Lightning Talk：聽其他人分享實作經驗，從真實案例中獲得靈感Lightning Talks: hear others' hands-on shares and get inspired
