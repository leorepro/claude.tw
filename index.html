這場活動適合誰 Who Should Attend

這場 workshop 會聚焦在如何為已經寫好的 Claude Code Skill設計 Evals，驗證它的品質與穩定性。因為會直接進入實作，適合已經自己寫過 Skill 的開發者；如果還沒寫過 Skill，難度會偏高，建議先累積一些經驗再來。 This workshop focuses on designing evals for a Claude Code Skill you've already built, to verify its quality and reliability. Since we dive straight into hands-on work, it's built for developers who have already written a Skill of their own — without that experience, it may be tough to keep up.

這場活動適合 This Event Is Perfect For

  • 已經自己寫過至少一個 Claude Code Skill 的開發者Developers who have already written at least one Claude Code Skill
  • 想確保自己的 Skill 品質穩定、行為可預期的人Anyone who wants their Skill's quality to be stable and its behavior predictable
  • 想學習如何設計 Evals 來驗證 Skill 正確性的人Anyone who wants to learn how to design evals that verify a Skill's correctness

你會帶走什麼 What You'll Take Away

  • 為既有 Skill 設計並撰寫一套 Evals 的完整流程A complete workflow for designing and writing an evals suite for an existing Skill
  • 找出 Skill 裡容易被忽略的邊界情況與潛在錯誤的方法Techniques for surfacing edge cases and hidden bugs your Skill might be missing
  • 可帶回日常工作的 Skill 開發與驗證最佳實踐Skill development and evaluation best practices you can bring back to daily work
  • 與其他開發者面對面交流的一小時An hour of face-to-face networking with fellow developers
